### 3. 如何管理

**检查守护进程状态**:
```powershell

```

**停止守护进程**:
```powershell
taskkill /F /IM python.exe
```

**手动运行修复**:
```powershell
cd D:\codex
python workflows\background_auto_fix.py
```
