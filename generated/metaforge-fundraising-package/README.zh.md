# MetaForge 融资材料包

这是一套面向中文投资人、设计伙伴和战略合作方的 MetaForge Control Console 融资材料包。

## 包含文件

- [one-pager.zh.md](./one-pager.zh.md)
- [pitch-deck.zh.md](./pitch-deck.zh.md)
- [demo-script.zh.md](./demo-script.zh.md)
- [data-room-checklist.zh.md](./data-room-checklist.zh.md)
- [financial-model-template.zh.md](./financial-model-template.zh.md)
- [business-plan.md](./business-plan.md)

## 对外定位

MetaForge 是面向研发团队的私有化 AI 任务控制台，覆盖目标导入、任务分发、执行可视化、证据链、发布门禁和私有化部署。

## 中文版与英文版分工

- 中文版适合中文投资人、国内产业合作方、中文试点客户。
- 英文版适合海外投资人、英文 design partner、国际化产品沟通。
- 商业企划书 `business-plan.md` 当前已经是中文，可作为中文长版商业计划书。

## 正式外发前必须补齐

- 创始人 / 团队履历与分工
- 融资金额、轮次、工具、估值或 cap
- 可公开的 traction 证据
- 公开 demo 链接或录屏
- 12 个月资金用途和关键里程碑
- 定价、销售管线和试点假设

## PDF 输出

同目录下的 `.pdf` 文件是当前可查看版本。正式外发前，应使用已补齐真实信息的最新版重新导出 PDF。
