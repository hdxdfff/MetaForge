# Data Room Checklist

## External-ready gate

Do not send the investor package externally until these are filled:

- founder / team bios
- funding amount, instrument, and valuation / cap
- public demo URL or screen recording
- at least one externally shareable traction proof point
- 12-month use-of-funds model

## Company

- legal entity information
- founder / employee roster
- cap table
- IP assignment docs
- major contractor agreements

## Product

- product one-pager
- pitch deck
- live demo link
- demo screenshot
- architecture overview
- deployment guide
- security boundary summary

## Traction

- pilot users
- internal usage notes
- customer conversations
- product feedback
- usage metrics
- milestone timeline

## Technical

- system architecture
- release / rollback flow
- task lifecycle documentation
- evidence chain documentation
- VM / private deployment instructions

## Financial

- 12-month budget
- current burn estimate
- runway estimate
- hiring plan
- revenue assumptions
- pricing model

## Fundraise

- amount raising
- use of funds
- milestone plan for next 6–12 months
- target customer segment
- go-to-market strategy

## Nice-to-have

- testimonials
- screenshots
- before/after workflow examples
- pilot contract template
