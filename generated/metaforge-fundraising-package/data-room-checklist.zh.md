# Data Room 清单中文版

## 外发前门禁

正式发送投资人材料前，必须补齐：

- 创始人 / 团队履历
- 融资金额、工具、估值或 cap
- 公开 demo URL 或录屏
- 至少一个可公开分享的 traction 证据
- 12 个月资金用途模型

## 公司

- 法人主体信息
- 创始人 / 员工名单
- 股权结构
- IP 归属文件
- 主要外包或顾问协议

## 产品

- 产品 one-pager
- pitch deck
- live demo 链接
- demo 截图
- 架构概览
- 部署说明
- 安全边界摘要

## Traction

- 试点用户
- 内部使用记录
- 客户访谈
- 产品反馈
- 使用指标
- 里程碑时间线

## 技术

- 系统架构
- 发布 / 回滚流程
- 任务生命周期文档
- 证据链文档
- VM / 私有化部署说明

## 财务

- 12 个月预算
- 当前 burn 估算
- runway 估算
- 招聘计划
- 收入假设
- 定价模型

## 融资

- 融资金额
- 资金用途
- 未来 6-12 个月里程碑计划
- 目标客户细分
- go-to-market 策略

## 加分项

- 客户推荐语
- 产品截图
- before / after 工作流案例
- 试点合同模板
