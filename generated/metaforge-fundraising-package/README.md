# MetaForge Fundraising Package

This package is the first-pass investor kit for MetaForge Control Console.
It now separates external-facing investor materials from internal planning notes so we do not send a draft that still needs the founder/fundraising inputs filled.

## Included

- [one-pager.md](./one-pager.md)
- [pitch-deck.md](./pitch-deck.md)

- [data-room-checklist.md](./data-room-checklist.md)
- [financial-model-template.md](./financial-model-template.md)

## Demo assets

- Internal demo artifact: `generated/metaforge-control-console-demo/index.html`
- Internal screenshot: `output/playwright/metaforge-control-console-demo.png`
- External package should use a hosted demo URL and hosted screenshot before sending to investors.

## Positioning

MetaForge is presented here as a private AI task control plane for R&D teams: task intake, dispatch, execution visibility, evidence, and release gating.

## Investor-facing language split

- `one-pager.md`, `pitch-deck.md`, and `demo-script.md` are the English investor-facing bundle.
- `business-plan.md` is the Chinese planning/reference version.
- If you want a single-language external packet, export only one language path and keep the other internal.

## What still needs founder input before formal outreach

- founder / team bios and roles
- exact funding ask: round, amount, instrument, valuation / cap
- traction proof that can be shared externally
- public demo URL or hosted screen recording
- 12-month use-of-funds allocation
- pricing and pipeline assumptions
