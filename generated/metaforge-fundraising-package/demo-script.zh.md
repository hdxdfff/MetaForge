# Demo Script 中文版

## 90 秒版本

1. “这是 MetaForge Control Console，一套面向研发团队的私有化 AI 任务控制台。”
2. “核心问题是：AI 自动化很容易启动，但很难被团队安全、持续地控制。”
3. “在这里，一个目标进入系统后，会被转化为可执行的任务 pipeline。”
4. “你可以看到 queued、running、completed 等状态。”
5. “证据门禁展示 build、smoke、manifest、checksum 和 release readiness。”
6. “关键点是：发布由实时事实控制，而不是旧快照或口头判断。”
7. “它面向私有化部署，团队可以把它跑在自己的 VM 或内网环境中。”
8. “一句话：它让 AI 工作流变得可审计、可恢复、可运营。”

## 3 分钟版本

### 开场

- 打开控制台 demo。
- 用一句话说明买方痛点：AI 自动化正在进入研发流程，但缺少控制面。

### 走一遍流程

- 展示任务 pipeline。
- 解释一个目标如何变成具体任务。
- 指出当前任务的排队、运行和完成状态。

### 展示证据

- 指向 build report、smoke report、manifest、checksum 和 release readiness。
- 强调证据必须是新鲜的，发布门禁才会通过。

### 收尾

- 说明产品面向私有化部署。
- 询问对方是否愿意进入试点或更深入的部署沟通。

## 常见异议处理

- **“这只是另一个 agent demo 吗？”**  
  不是。它是带证据链和发布门禁的执行控制面。

- **“能私有化运行吗？”**  
  可以。产品设计从一开始就面向 VM、内网和受控环境。

- **“如何防止自动化失控？”**  
  通过把执行、证据和发布都放在显式门禁下。

- **“第一个落地场景是什么？”**  
  工程工作流控制和可审计 AI 任务编排。
