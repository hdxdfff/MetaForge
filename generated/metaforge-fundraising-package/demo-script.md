# Demo Script

## 90-second version

1. "This is MetaForge Control Console. It is a private AI task control plane for engineering teams."
2. "The key problem is that AI automation is easy to start but hard to control."
3. "Here, a goal enters the system and becomes a task pipeline."
4. "You can see queued, running, and completed states."
5. "The evidence gate shows build, smoke, manifest, checksum, and release readiness."
6. "The important part: release is gated by live facts, not stale snapshots."
7. "This is designed for private deployment, so teams can run it inside their own VM or internal environment."
8. "In short: it makes AI workflows auditable, recoverable, and operationally safe."

## 3-minute version

### Start
- Open the control console demo.
- Point at the headline and explain the buyer pain in one sentence.

### Walk the flow
- Show the task pipeline.
- Explain how a goal becomes concrete work.
- Highlight the current task statuses.

### Show evidence
- Point to build report, smoke report, manifest, checksum, and release readiness.
- Emphasize that evidence must be fresh.

### Close
- Explain that the product is intended for private deployment.
- Ask whether the team wants a pilot or a deeper deployment conversation.

## Objection handling

- **"Is this just another agent demo?"**  
  No — it is an execution control plane with evidence and release gating.

- **"Can we run it privately?"**  
  Yes — the design is explicitly private-deployment friendly.

- **"How do you prevent runaway automation?"**  
  By keeping execution, evidence, and release under explicit gates.

- **"What is the first use case?"**  
  Engineering workflow control and auditable AI task orchestration.
