# 财务模型模板

> 这是用于投资人沟通的第一版基线模型。正式外发前，请替换为真实定价、销售管线和创始人主导销售计划。

## 目标

第一版模型应足够简单，让投资人能快速判断融资效率、收入路径和成本结构。

## 收入来源

| 收入流 | 描述 | 第 1 个月 | 第 6 个月 | 第 12 个月 |
|---|---|---:|---:|---:|
| 团队订阅 | 面向小团队的私有化控制台 | 0 | 1 | 4 |
| 企业订阅 | 私有化部署 + 支持 | 0 | 0 | 2 |
| 部署服务 | 安装、集成、onboarding | 1 | 2 | 4 |
| 支持 / 定制 | 持续技术支持 | 0 | 1 | 2 |

## 核心假设

- 平均合同金额：团队版 USD 24k / 企业版 USD 120k
- 销售周期：60-90 天
- 设计伙伴数量：3-5 个
- 试点转付费比例：25%-40%
- 目标毛利率：75%-85%

## 成本结构

| 成本项 | 说明 | 月度估算 |
|---|---|---:|
| 研发 | 产品开发 | 1 |
| 云 / VM / 工具 | 基础设施和工具 | 0.35 |
| 销售 / 创始人 GTM | 外联和 demo | 0.5 |
| 法务 / 行政 | 公司运营 | 0.15 |

## 12 个月资金用途基线

| 类别 | 占比 |
|---|---:|
| 产品稳定性增强 | 40% |
| 私有化部署 / 企业能力 | 20% |
| 设计伙伴支持 | 15% |
| GTM / 创始人主导销售 | 15% |
| 基础设施 / 法务 / 行政 | 10% |

## 12 个月里程碑模型

| 月份 | 产品里程碑 | 商业里程碑 |
|---|---|---|
| 1 | demo finalized | first design conversations |
| 3 | pilot-ready package | first pilot candidate |
| 6 | stable private deployment | first paid engagement |
| 12 | repeatable workflow | multi-customer pipeline |

## 投资人会重点看什么

- 客户痛点是否可信
- 是否能快速进入付费试点
- 毛利和服务策略是否清晰
- 产品是否能私有化部署
- 是否能从一个工作流扩展到多个工作流
- 融资金额、轮次和资金用途是否明确
