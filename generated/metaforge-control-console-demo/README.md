# MetaForge Control Console Demo

Static single-page demo for the product story: a private AI control console that turns goals into queued tasks, running work, evidence, and release gates.

## Open

Open `index.html` in any browser.

## What it shows

- Goal intake
- Task queue
- Execution timeline
- Fresh evidence gate
- Release-readiness snapshot

## Notes

This is a front-end demo only. It does not depend on a backend or local service.
